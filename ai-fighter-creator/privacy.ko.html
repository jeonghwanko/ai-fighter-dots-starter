운영자와 적용 범위

운영자는 Lucas Foundation이며 AI Fighter Creator 플러그인과 연결된 ODDBOUT 캐릭터 서비스에 적용됩니다. 개인정보 문의: turbo08@gmail.com. 이 정책의 게시는 OpenAI 공식 디렉터리 승인을 의미하지 않습니다.

Codex와 생성 제공자는 각자의 정책에 따라 정보를 처리합니다. 로컬 플러그인을 사용하더라도 대화와 도구 결과가 모두 내 컴퓨터 안에만 머무르는 것은 아닙니다.

02

컴퓨터에 저장되는 정보

프로젝트 설명, 참고·결과 파일 경로, 보존된 에셋 버전, 선택 이력, 검토 자료와 피드백, 게임 규격 버전, 프로필 초안, 작업 기록을 저장합니다. 작업 기록에는 프롬프트를 포함한 실행 인수, 제공자 선택, 파일 해시·크기, 시각, 프로세스 상태와 진단 출력이 포함될 수 있습니다. 작업 재개, 선택 보존, 불확실한 실행 확인 및 파일 검증에 사용합니다.

기본 작업 폴더는 ~/.ai-fighter/creator/workspace/, 실행 파일 사본은 ~/.ai-fighter/creator/runtimes/입니다. 설정에 따라 달라질 수 있습니다. ODDBOUT 로그인 시 접근·갱신 토큰과 공개 서비스 설정은 기본적으로 ~/.ai-fighter/client.json에 저장됩니다. 생성 제공자 인증정보는 해당 도구가 관리합니다.

03

Codex에 반환되는 정보

도구 요청과 결과는 호스트 어시스턴트에 전달됩니다. 요청에 따라 설명·프로필, 절대 경로를 포함한 파일 경로, 명령과 로그, 검토 메모, 근거 경로, 버전·시각·해시, 검증 오류, 제출 상태, 캐릭터 ID와 등록 정보가 포함될 수 있습니다. 이 필드에 사용자가 적은 개인정보도 포함될 수 있습니다. 요청한 미리보기나 파일을 어시스턴트가 열람할 수도 있습니다.

OpenAI의 처리는 사용하는 제품·계정 설정과 OpenAI 개인정보 정책을 따릅니다. 홈페이지 열기 도구가 반환하는 로그인 링크는 10분간 유효한 일회성 접근 정보이므로 본인이 열고 공개하거나 전달하지 마세요.

04

외부 전송과 공개

  • 규격·환경 준비: 공개 GitHub 또는 ODDBOUT 주소에서 게임 규격을 읽으며, 환경 설치 시 패키지 저장소에 요청과 일반 연결 정보가 전달됩니다.
  • 생성: 선택한 OpenAI·xAI 등 제공자에 프롬프트, 선택한 참고 파일, 요청·계정 정보가 전송됩니다. 해당 계정의 정책과 이용료가 적용됩니다. 작업 준비만으로 생성이 실행되지는 않습니다.
  • 로그인: Google 계정 식별자, 이메일과 이름·사진 등 기본 프로필이 Supabase 인증을 통해 처리됩니다. Google 비밀번호를 받지 않습니다.
  • 등록: 요청한 패키지의 프로필·그림·애니메이션·게임 설정, 소유 관계, 시각, 해시, 검증·관리 기록이 ODDBOUT의 Supabase 서비스와 검증 작업자에서 처리됩니다.
  • 문의: 발신 주소, 메시지, 첨부파일을 지원 메일함에서 처리합니다.

등록 성공 시 프로필, 그림, 애니메이션, 게임 설정, 식별자와 공개 경기·순위 기록을 다른 사람이 열람하거나 내려받을 수 있습니다. 로그인 이메일과 인증 토큰은 공개 캐릭터 프로필 필드가 아닙니다. 로컬 초안이 자동으로 등록되지는 않으며, 이미 내려받은 사본을 회수할 수는 없습니다.

05

처리 제공자

Supabase는 인증·데이터베이스·저장소·API, GitHub Pages는 정적 호스팅, Render는 패키지 검증, Google은 로그인·지원 이메일에 사용됩니다. 생성 제공자는 사용자가 선택합니다. IP 주소, 브라우저 정보, 요청 시각과 운영 로그가 처리될 수 있으며, 제공자와 계정에 따라 거주 국가 밖에서 처리될 수 있습니다. 서비스 처리 위치와 보호조치 관련 정보는 운영자에게 문의할 수 있습니다. 계정 없이 쓰는 기능의 남용을 막기 위해, IP 주소에서 비밀 키로 만든 날마다 바뀌는 코드로 방문자별 요청 수를 셉니다. IP 주소 자체는 저장하지 않으며 이 기록은 하루 안에 삭제됩니다.

Supabase · GitHub · Render · Google · OpenAI · xAI

이 정책 페이지에는 분석·광고 스크립트나 외부 미디어 임베드가 없습니다. 플러그인의 별도 분석 수집기도 없습니다. 호스팅 로그 및 호스트·제공자 정책은 적용됩니다. 개인정보를 판매하거나 플러그인에서 결제카드 정보를 수집하지 않습니다. 법적 요구나 사기·오용·보안사고 대응을 위해 필요한 정보가 제공될 수 있습니다.

06

보유와 삭제

로컬 프로젝트와 작업 기록에는 자동 만료가 없으며 직접 삭제할 때까지 남습니다. 플러그인 제거만으로 별도 작업 폴더·실행 사본·제공자 데이터가 지워지지 않습니다. 로그아웃은 로컬 세션 파일을 지우고 서버 세션 취소를 시도하지만 계정·프로젝트·캐릭터를 삭제하지 않습니다.

서비스의 계정·캐릭터·경기 정보는 서비스 제공, 경기 이력, 지원·보안·관리 목적에 필요한 동안 보유합니다. 삭제 요청 시 남아 있는 법적·보안·기록 무결성 필요를 검토합니다. 로그·문의·백업은 목적과 제공자 설정에 따라 보유되며 백업 만료에는 더 시간이 걸릴 수 있습니다. 업로드 만료나 비공개 처리는 모든 파일 삭제를 뜻하지 않습니다. 구현되지 않은 자동 계정 삭제나 고정 처리 기한을 약속하지 않습니다.

07

권리와 문의

ODDBOUT 로그인 없이 로컬 프로젝트 기능을 이용하거나 생성을 거절하고 등록 전에 중단할 수 있습니다. 로컬 파일 삭제, 로그아웃, Google 연결 해제는 별개이며, 연결 해제만으로 이미 전송된 정보가 삭제되지는 않습니다.

열람·정정·사본·캐릭터 제거·계정 삭제는 계정 이메일로 turbo08@gmail.com에 요청해 주세요. 관련 ID나 공개 링크를 포함하면 도움이 됩니다. 소유 확인에 필요한 정보를 요청할 수 있으며, 삭제하지 못하는 보유 사유가 있으면 설명합니다. 비밀번호·토큰·세션 파일은 보내지 마세요. 적용 법률에 따라 처리 제한·이의 제기·동의 철회·감독기관 신고 등의 권리가 있을 수 있습니다. Codex 대화나 생성 계정 데이터는 해당 제공자에도 요청해야 합니다.
