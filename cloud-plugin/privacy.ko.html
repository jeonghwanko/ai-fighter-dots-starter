02

받는 정보

Google 로그인에서 계정 식별 정보·기본 프로필·이메일을 받습니다. 발급된 이메일 계정도 로그인할 수 있으며, 비밀번호는 HTTPS로 Supabase Auth에 직접 전달되고 연결 도구 요청에는 포함되지 않습니다. 연결 도구는 OAuth 권한과 작업에 선택된 인자·파일을 처리합니다. 여기에는 캐릭터 메타데이터, 매니페스트, 애니메이션 에셋, 제출 식별자와 상태 조회 요청이 포함됩니다. Google 비밀번호나 생성 제공자 인증정보, PC 설치는 요구하지 않습니다.

03

이용 목적

소유자 식별, 본인 제출물 접근 제한, 패키지 검증, 등록 처리, 등록 캐릭터 제공, 장애·오용 조사에 사용합니다. 연결 도구의 권한은 일반 데이터베이스·스토리지 로그인 권한으로 사용할 수 없습니다.

04

등록 분석

ODDBOUT 웹사이트에 로그인한 상태에서 유효한 분석 연결 기록을 제공한 경우, 등록 완료 시 기존 Analytics 클라이언트 식별자, 유효한 세션 식별자, 이벤트 이름과 등록 시각이 Google Analytics에 전송될 수 있습니다. 로그인 이메일, 계정·제출·캐릭터 ID, 인증 토큰과 캐릭터 파일은 분석 이벤트 항목에 포함하지 않습니다. 웹사이트와 등록 사이의 이용 흐름을 측정하며 등록의 필수 조건은 아닙니다. 웹사이트에서 분석을 거부한 상태로 로그인해 방문하면 저장된 연결 기록을 지우고 대기 중인 이벤트를 취소합니다.

05

처리 제공자와 공개 정보

Google은 소셜 로그인을, Supabase는 인증·등록 데이터·스토리지를 제공합니다. Render는 OAuth 접근 토큰을 포함한 공개 MCP 요청을 고정된 Supabase MCP 서버로 전달하고 패키지를 검증합니다. GitHub Pages는 연결·안내 페이지를, OpenAI는 Dots와 연결 호스트를 제공합니다. 제공자는 이용자의 국가 밖에서 정보를 처리할 수 있습니다. 등록된 캐릭터 프로필·그림·애니메이션·게임 패키지는 공개되며, 로그인 이메일과 인증 토큰은 공개 패키지에 포함되지 않습니다.

06

보관 기간

계정·소유권 기록, 업로드한 매니페스트·파일, 등록 결과, 경기 이력과 삭제 영수증에는 현재 자동 파기 일정이 없습니다. 반려·업로드 만료·캐릭터 삭제 후에도 별도의 보관 종료일 없이 보관합니다. 업로드는 24시간 후 닫히지만 파일이 지워지는 것은 아닙니다. 삭제 확인값의 사용 기한은 10분이며 서명된 에셋 링크는 최대 10분 안에 만료됩니다. 이 기한은 원본 파일이나 기록의 파기 시점이 아닙니다. ODDBOUT 데이터베이스의 등록 분석 연결 기록과 전송 대기 기록은 마지막 갱신 또는 생성 후 29일이 지나면 매시간 정리합니다. 이는 인프라·분석 제공자가 이미 처리한 사본의 보관과는 별개입니다.

삭제와 완전 파기 요청

Dots에서 캐릭터를 삭제하면 내 활성 목록·공개 목록·새 대전에서 제거하고 슬롯을 비웁니다. 비공개 원본과 과거 기록은 남습니다. 계정 데이터나 원본 파일의 열람·정정·완전 파기는 turbo08@gmail.com으로 요청하세요. 소유권을 확인하고 요청 범위, 관련 경기 이력과 적용되는 보존 의무를 검토한 뒤 처리 결과를 안내합니다. 요청 접수·연결 해제·삭제 확인만으로 파일 파기가 완료되는 것은 아닙니다. 자동 파기 기한은 없으며 실제 파기 처리가 완료될 때까지 보관합니다. 남겨야 하는 항목은 답변에서 설명합니다. 이미 내려받은 공개 사본은 회수할 수 없을 수 있습니다.
