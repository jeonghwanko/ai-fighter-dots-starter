01

제공자

공개 플러그인 게시자는 정환 고이며, ODDBOUT 서비스는 Lucas Foundation이 운영합니다. 개인정보 문의와 데이터 요청은 turbo08@gmail.com으로 보내 주세요.

02

받는 정보

Google 로그인에서 계정 식별 정보·기본 프로필·이메일을 받습니다. 발급된 이메일 계정도 로그인할 수 있으며, 비밀번호는 HTTPS로 Supabase Auth에 직접 전달되고 연결 도구 요청에는 포함되지 않습니다. 연결 도구는 OAuth 권한과 작업에 선택된 인자·파일을 처리합니다. 여기에는 캐릭터 메타데이터, 매니페스트, 애니메이션 에셋, 제출 식별자와 상태 조회 요청이 포함됩니다. Google 비밀번호나 생성 제공자 인증정보, PC 설치는 요구하지 않습니다.

03

이용 목적

소유자 식별, 본인 제출물 접근 제한, 패키지 검증, 등록 처리, 등록 캐릭터 제공, 장애·오용 조사에 사용합니다. 연결 도구의 권한은 일반 데이터베이스·스토리지 로그인 권한으로 사용할 수 없습니다.

04

처리 제공자와 공개 정보

Google은 소셜 로그인을, Supabase는 인증·등록 데이터·스토리지를 제공합니다. Render는 OAuth 접근 토큰을 포함한 공개 MCP 요청을 고정된 Supabase MCP 서버로 전달하고 패키지를 검증합니다. GitHub Pages는 연결·안내 페이지를, OpenAI는 Dots와 연결 호스트를 제공합니다. 제공자는 이용자의 국가 밖에서 정보를 처리할 수 있습니다. 등록된 캐릭터 프로필·그림·애니메이션·게임 패키지는 공개되며, 로그인 이메일과 인증 토큰은 공개 패키지에 포함되지 않습니다.

05

보관과 선택

Dots에서 캐릭터 삭제를 요청할 수 있습니다. 소유권과 삭제 의사를 확인한 뒤 내 목록·공개 목록·새 대전에서 제거하고 등록 슬롯을 비웁니다. 비공개 원본 패키지와 과거 기록은 보관하며 파일 완전 삭제는 아닙니다. 이미 발급된 에셋 링크는 최대 10분 이내 만료됩니다. 계정 데이터 열람·정정·완전 삭제는 지원 주소로 문의하세요. 연결 해제만으로 캐릭터가 삭제되지는 않으며 이미 내려받은 공개 사본은 회수할 수 없을 수 있습니다.

06

안전한 문의

관련 계정 이메일, 공개 캐릭터 ID와 간단한 설명만 보내 주세요. 비밀번호·OAuth 콜백·접근 토큰·서명된 다운로드 주소는 보내지 마세요. 이 안내가 바뀌면 이 페이지에 게시합니다.
