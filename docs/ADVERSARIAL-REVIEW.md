## 아직 막혀 있는 제품 출시 조건

1. **등록 기능 부재.** 이 샘플은 서버에 선수를 등록하지 않는다.
   인증된 제출, 불변 파일 보관, 서버 재검사, 중복 등록 방지와 상태 조회가 필요하다.
2. **게임의 동적 소비와 공정성.** 외형 패키지 통과만으로 양쪽 선수에 같은 경쟁 규칙이 적용되지 않는다.
   공통 전투 kit, 승인된 버전의 동적 로딩, 같은 선수 ID의 중복 배치 방지가 필요하다.
3. **품질 판단.** 발 교대·접지·연타·넘어짐·얼굴 일관성은 알파·크기 검사로 증명되지 않는다.
   새로 만든 선수 하나를 실제 양쪽 전투 소비자로 재생하는 시연이 필요하다.
4. **원격 공격자 격리.** 로컬 작업자는 신뢰하는 작업 폴더용이다.
   V8 힙 제한은 네이티브 이미지 메모리의 강제 상한이 아니며, 경로 검사도 동시 파일 교체 공격의 완전한 방어가 아니다.
   원격 베타는 불변 다운로드 디렉터리, OS 메모리·CPU 격리, 검증 작업 임대와 복구가 필요하다.
5. **실제 Dot 사용성.** SDK 통합 시험은 통과했지만 모든 계정·호스트 UI의 도구 노출과 이미지 제작 능력을 보증하지 않는다.
   README의 첫 검사 요청으로 설치를 확인한 뒤 새로운 캐릭터 제작으로 이어간다.

`ok: true`와 `pending`을 함께 반환하며 `approved`, `fighterId`, `registered`를 만들어 내지 않는다.
