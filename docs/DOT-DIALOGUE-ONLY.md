# 실제 Dot에서 대화 흐름만 시험하기

시험에 보낼 주소는 [게임 규격이 한 문서에 포함된 대화 시험 링크](https://github.com/jeonghwanko/ai-fighter-dots-starter/blob/codex/game-context/DIALOGUE-ONLY.md)입니다.
이 이전 안내 주소를 먼저 받았다면 첫 응답 전에 위 문서의 JSON까지 읽고, 읽은 revision 앞 12자리를 짧게 밝힙니다.
안내만 읽고 구조 데이터를 확인했다고 말하지 않습니다. 아래의 실행 제한도 함께 지킵니다.

이 링크를 보내는 사용자는 **실제 제작 없이 대화 흐름을 시험**하려고 합니다.
이 링크 자체가 시험 시작 요청입니다. 시작 여부를 다시 확인하지 않고, 아래 자료를 읽은 뒤
원하는 캐릭터의 설명이나 참고 이미지를 짧게 요청합니다. 사용자 역할의 답은 작성하지 않습니다.
이 메시지부터 새 테스트를 시작합니다. 이 문서는 실행 범위만 제한하며,
질문의 내용과 묶음별 대화 방식은 [현재 제작 시작 안내](START-HERE.md)를 따릅니다.

## 테스트 범위

- 현재 링크 메시지 이후의 사용자 입력과 이 저장소의 공개 제작 안내만 사용합니다.
  이전 Dot·ChatGPT·Codex 대화, 과거 테스트 결과, 기존 캐릭터, 개인 메모를
  검색하거나 조회하지 않습니다. 이미 알고 있는 이름·선택·구독 확인도 이어받지 않습니다.
- `START-HERE.md`와 필요한 공개 제작 규격은 읽을 수 있습니다.
  특히 [게임의 현재 구조 데이터](https://raw.githubusercontent.com/jeonghwanko/ai-fighter-dots-starter/refs/heads/codex/game-context/creation-context.json)를
  읽고 `revision`, `workflow`, `contract`, `controls`, `timing`을 이번 시험의 기준으로 사용합니다.
  현재 묶음에 해당하는 규격으로 질문하고 선택·수정 상태를 유지합니다. 미확정 외형의 세부 답을 전체 선택으로 간주하지 않습니다.
  과거 대화 평가 보고서, 응답 예시 파일, 테스트 시나리오·정답 파일은 읽지 않습니다.
- 이미지·영상·스프라이트·캐릭터 패키지를 실제 생성하거나 편집하지 않습니다.
  설치, 생성 계정 접근, 로그인, 업로드, 등록, 배포도 실행하지 않습니다.
- 별도 Work·Codex 작업이나 하위 에이전트에 맡기지 않고, 이 Dot 대화에서 직접 답합니다.
  다른 채팅에 보고하거나 메시지를 보내지 않습니다.
- 사용자가 나중에 시안·동작·검사 결과를 봤다고 말하면 모의 상황으로만 해석합니다.
  실제 파일이나 미리보기가 존재하거나 검사가 통과했다고 주장하지 않습니다.
- 한 번에 사용자에게 필요한 다음 응답만 하고 답을 기다립니다.
  사용자 역할의 답을 대신 만들거나, 혼자 전체 테스트 시나리오를 끝내지 않습니다.

## 시작

[제작 시작 안내](START-HERE.md)를 읽고, 아직 캐릭터 설명을 받지 않은 상태에서 시작합니다.
시험 중 상태와 검수는 `dialogue-only` / `hypothetical`입니다. 읽기 전용 규격 확인은 가능하지만
진행 상태 도구가 연결되지 않았다면 `workflow.gates`를 직접 대조하고, 도구 검사에 통과했다고 말하지 않습니다.
이 문서의 제한은 실제 제작을 수행하는 안내보다 우선합니다.
사용자가 테스트를 마치면 멈춥니다. 실제 생성으로 바꾸려면 이후 명시적인 새 요청이 필요합니다.

## 해석상의 한계

Dot은 기존 기억을 유지하는 제품입니다. 이 문서는 이전 기록 조회와 사용을 금지하는
테스트 지시이며, 제품의 기억을 초기화하거나 시스템 수준의 격리를 제공하지 않습니다.
실제 생성 품질, 생성 중 단계별 정지, 계정 접근 및 등록 성공은 이 대화 시험만으로 검증되지 않습니다.
